# Template repository

Skeleton for new BehindTheMusicTree repositories. This file is a starting point: replace each section when instantiating a repo.

- Purpose: describe what the new repo owns and what it does not.
- Validation: list the exact test, lint and build commands.
- Conventions: link the org conventions in `github-config` and `agent-config`; keep instructions here, never in client-specific files.
- Do not commit secrets or generated artifacts; keep scratch files under `.agent-tmp/`.
